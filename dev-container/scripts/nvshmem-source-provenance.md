# NVSHMEM source provenance

The CUDA 13 Debian binary packages `libnvshmem3-cuda-13` and
`libnvshmem3-dev-cuda-13`, version `3.7.2-1`, correspond to the official NVIDIA
NVSHMEM release `v3.7.2-0` at commit
`3f4c6d81225f45f9c42ed9af09bdb3c61eb356d4`.

The adjacent `nvshmem-3f4c6d81225f45f9c42ed9af09bdb3c61eb356d4.tar.gz`
is the unmodified source archive downloaded from the official
[NVIDIA/NVSHMEM repository](https://github.com/NVIDIA/nvshmem). Its SHA-256 is
`16ffdc0dad774e1048e0ff648464262d95d6584ace8528da320b72db696b3ba2`.
The archive retains the upstream `License.txt` and `NOTICE` files.
