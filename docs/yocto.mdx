NVIDIA Holoscan accelerates deployment of production-quality applications
by providing a set of **OpenEmbedded** build recipes and reference configurations
in the [meta-tegra-community](https://github.com/NVIDIA/meta-tegra-community) project.
A developer can leverage those recipes to customize and build Holoscan-compatible OpenEmbedded for Tegra (OE4T)
embedded board support packages (BSP) on the NVIDIA Jetson AGX Developer Kits.

An OpenEmbedded build is done on a developer's host machine and is then flashed onto the NVIDIA Jetson AGX
Developer Kit using provided scripts.

To get started with a demo image that includes Holoscan SDK, use
[tegra-demo-distro](https://github.com/NVIDIA/tegra-demo-distro). A tutorial covering
the steps to build and deploy the demo image is coming soon in
[holoscan-tutorials](https://github.com/nvidia-holoscan/holoscan-tutorials).
