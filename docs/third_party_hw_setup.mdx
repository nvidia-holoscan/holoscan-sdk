GPU compute performance is a key component of the Holoscan hardware
platforms, and in order to optimize GPU-based video processing applications and provide
lowest possible latency, the Holoscan SDK supports several cameras and capture cards available, as well as a variety of community-contributed operators and device integrations via [Holohub](https://github.com/nvidia-holoscan/holohub),
and the Holoscan Sensor Bridge.

The following sections provide more information on how to setup the system with these
technologies.
