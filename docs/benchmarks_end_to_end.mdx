This page will collect end-to-end results for complete applications built on the
SDK's example apps — as opposed to the microbenchmarks on the
[channel benchmarks](/holoscan/sdk-user-guide/performance/channel-benchmarks) and
[core runtime benchmarks](/holoscan/sdk-user-guide/performance/core-runtime-benchmarks)
pages, which isolate individual primitives. End-to-end numbers measure what an
application actually experiences: sensor-to-actuation latency through a full
graph, jitter under sustained load, and throughput across process boundaries.
